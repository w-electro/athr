# العرض التقديمي — كيف يُبنى

ملفّ `athr-pitch-ar.pptx` في جذر المستودع مولَّد، لا مكتوبٌ بيد. وهذا
المجلّد هو مصدره.

```bash
node tools/deck/build.cjs          # يكتب athr-pitch-ar.pptx
python tools/deck/morph.py         # يضيف انتقال Morph إلى الملفّ نفسه
```

الترتيب مقصود: `morph.py` يعدّل XML الشرائح بعد توليدها، فتشغيله قبل
البناء لا معنى له، وتشغيله مرّتين يسقط عند تأكيدٍ داخله.

## لماذا خطوتان

pptxgenjs لا يكتب انتقال Morph — وهو الانتقال الذي يجعل العنوان ينساب
بين شريحةٍ وأخرى بدل أن يُقطع. فيُضاف بعد التوليد وسمًا في `<p:sld>`،
ومعه اسمٌ يبدأ بعلامتَي تعجّب (`!!title`) على عنوان كلّ شريحة: بهذا
يزاوج PowerPoint العنوانَين يقينًا لا تخمينًا.

## الرسوم

```bash
python tools/deck/art/glyphs.py    # رموز النقش الصخري  -> assets/ic-*.png
python tools/deck/art/cover.py     # غلاف الشريحة الأولى -> assets/cover.jpg
python tools/deck/art/thumbs.py    # مصغّرا المخطّط       -> assets/thumb-*.jpg
```

الثلاثة تقرأ من `public/photos/` وتكتب في `assets/`، فتشغيلها يعيد
إنتاج ما هو موجود بالضبط. ولا مكتبة SVG هنا: `cairosvg` يحتاج
`libcairo` وهي غائبة عن ويندوز، فالرسم بـPIL مباشرةً.

## ملفّات لا يعيدها سكربت

هذه في `assets/` ولا مولّد لها، فلا تحذفها:

| الملفّ | من أين |
|---|---|
| `glyph-ibex.png` | وعل `Petroglyph.jsx` مُلتقطًا من المتصفّح |
| `app-welcome.png` · `app-site.png` | لقطتان من التطبيق بعرض 412 بكسل |
| `qr.png` | رمز الاستجابة لعنوان النشر |

## الخطوط

الشرائح تستعمل خطَّي الموقع: **Reem Kufi** للشعار و**Tajawal** للنصّ
(كلاهما SIL OFL). فإن لم يكونا مثبَّتين على الجهاز الذي يعرض، استبدل
PowerPoint بهما غيرَهما وتغيّر المقاس. ولهذا يُشحن `athr-pitch-ar.pdf`
إلى جانب العرض: يحمل الخطوط في جوفه، وإن فقَد انتقال Morph.

# شاشة الجناح الرأسية

ملفٌّ ثانٍ منفصل: `athr-screen-ar.pptx`. لشاشةٍ قائمة تُدار وحدها —
يبدأ برمز الاستجابة كبيرًا ليمسحه المارّ، ثمّ يعرض لوحات جبة العشر،
ثمّ يعود إلى الرمز.

```bash
python tools/deck/art/screen-photos.py   # يهيّئ الصور -> assets/screen/
node   tools/deck/screen.cjs             # يكتب athr-screen-ar.pptx
python tools/deck/autoplay.py            # يضيف التوقيت والتكرار
```

المقاس 7.5 × 13.333 بوصة — أي 9:16، وهي نسبة الشاشة الرأسية ونسبة
الصور الأصلية معًا (2268×4032 من الجوّال)، فلا قصّ ولا حشو.

## المقاس

الشاشة **1504 × 2256**، أي 2:3 — والشريحة مقاسها مشتقٌّ منها في
`screen.cjs` كي لا تنفصل عنها. ونسبةُ الشريحة يجب أن تطابق نسبة الشاشة
بالضبط: أيُّ فارقٍ يُدخله باوربوينت في الشاشة ويحشو الباقي شريطين
جانبيين. ولو تغيّرت الشاشة، غيّر `SCREEN_W`/`SCREEN_H` وأعد التشغيل.

والأصل من الجوّال 2268×4032، أي 9:16 — أطولُ نسبيًّا، فيُقصّ من ارتفاعه.
ولكلّ صورةٍ ميلُ قصٍّ في رأس `screen-photos.py`: صفرٌ يُبقي الأعلى، وواحدٌ
الأسفل. وأظهرُ حالةٍ مَلِك جبة — تاجُه هو ما يُعرف به، وقصُّ الوسط كان
يقطعه.

## التقدّم

**بالضغط لا بالوقت.** و`autoplay.py` يكتب `loop="1"` فقط، فتعود الضغطةُ
بعد آخر شريحة إلى الأولى بدل أن تُنهي العرض.

ولشاشةٍ تمشي وحدها بلا يد:

```bash
python tools/deck/autoplay.py --auto                  # 12ث للرمز، 6ث للوحة
python tools/deck/autoplay.py --auto --qr 15 --panel 8
```

وحينها يبقى `advClick` مرفوعًا فتظلّ اليد قادرةً على التقديم — ولذلك
اختيرت `<p:present/>` لا `<p:kiosk/>`، فالأخيرة تمنع اللمس أصلًا.

**للتشغيل:** افتح الملفّ واضغط F5.

## اختيار اللقطات

لكلّ لوحةٍ حُسب مركزُ متجهاتها في `public/reference-index.json`، وأُخذت
أقربُ صورةٍ إليه — أي أكثرُها تمثيلًا للّوحة بحساب النموذج نفسه. ثمّ
رُوجعت العشر بالعين واستُبدلت ثلاث. الأسماء في رأس `screen-photos.py`.

الصور الخام في `photos-inbox/` وهي **غير متتبَّعة في git**، فالسكربت لا
يعمل إلا على جهازٍ فيه التصوير الميداني. والمخرجات في `assets/screen/`
متتبَّعة، فالعرض يُبنى بدونها.

# ورقتان مطبوعتان

ملفّان مستقلّان عن العروض، كلاهما A4 وصفحتان:

```bash
python tools/deck/build-intro.py    # athr-intro-ar.pdf   — الشرح السريع للحفظ
python tools/deck/build-design.py   # athr-design-ar.pdf  — التصميم الأولي
```

كانا نصًّا صِرفًا أوّلًا فخرجت العربية مبعثرة: محرّرات txt لا تضبط اتجاه
سطرٍ تجتمع فيه عربيةٌ وأرقامٌ ولاتينية، لأنّ الاتجاه يُحسب عند العرض لا
عند الحفظ. والـPDF يثبّته.

والمسار pptxgenjs ثمّ ليبر أوفيس، والـpptx الوسيط في مجلّدٍ مؤقّت.

## لقطات الشاشات

`assets/screens/` لقطاتٌ من التطبيق وهو يعمل، لا رسومًا تحاكيه. تُلتقط
بـPlaywright من البناء المشحون على خادمٍ محلّي. ولها مصيدتان:

  · اللغة وحدها لا تتخطّى شاشة الاختيار — البوّابة `athr.onboarded`
    ومفتاحها مستقلّ عن `athr.language`. فتُزرع الاثنتان.
  · وتُزرعان بـ`addInitScript` قبل سكربتات الصفحة، لا بعد التحميل:
    الانتقال إلى `#/explore` على العنوان نفسه لا يُعيد التحميل أصلًا.
