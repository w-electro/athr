# دفاتر أثر

## `build-reference-index.ipynb` — بناء فهرس التعرّف

يحوّل صورك من المواقع إلى ملف `reference-index.json` يضعه التطبيق في
`public/`، فيتعرّف على المواقع من كاميرا الزائر داخل المتصفح، بلا خادم
وبلا إنترنت بعد التحميل الأول.

**لا يحتاج خبرة في تعلّم الآلة، ولا يحتاج كرت شاشة.** كل خلية مشروحة
بالعربية داخل الدفتر.

### التشغيل

1. افتح [kaggle.com](https://www.kaggle.com) → **Create** → **New Notebook**
2. **File → Import Notebook** وارفع `build-reference-index.ipynb`
3. اترك المسرّع على **CPU** (لا تستهلك حصّة الـ GPU، لا حاجة لها هنا)
4. ارفع صورك كـ Dataset بالبنية الموضّحة في الخطوة ٢ داخل الدفتر
5. شغّل الخلايا بالترتيب

### البنية المطلوبة للصور

```
athr-photos/
├── jubbah/       ١٥–٣٠ صورة   (الاسم = id في sites.js)
├── qishlah/
├── aja/
├── museum/
└── _negatives/   ٥٠ صورة لا تخصّ أي موقع
```

`_negatives` ليست اختيارية عمليًا: بدونها لا يستطيع النظام قول «لا أعرف»،
فيعطي إجابات واثقة خاطئة — وهي أسوأ ما يمكن أن يحدث أمام لجنة تحكيم.

### ⚠️ قاعدة واحدة لا تُخالَف

`MODEL_ID` و`DTYPE` في الدفتر يجب أن يطابقا `MODEL_ID` و`MODEL_DTYPE` في
`src/lib/recognition.local.js`.

الفهرس وصورة الكاميرا يمرّان بالنموذج نفسه، وإلا فالأرقام لا تعني الشيء
نفسه والنتائج تصبح عشوائية. التطبيق يتحقّق من هذه البصمة ويرفض الفهرس
غير المطابق مع تحذير في الطرفية — لكن الأفضل ألا تصل إلى ذلك.
